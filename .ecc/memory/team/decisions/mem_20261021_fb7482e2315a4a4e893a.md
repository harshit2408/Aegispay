- Agent/skill/rule selection is deterministic: .claude/routing.json (UserPromptSubmit hook) + path-scoped .claude/rules/. Change routing by editing the JSON.
- After every passing test command the post-test-sync hook runs git pull --rebase --autostash and pushes local commits (AEGIS_AUTOPUSH=0 disables push). Failing tests never push.
