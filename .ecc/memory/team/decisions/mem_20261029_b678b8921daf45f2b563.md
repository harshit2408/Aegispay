2026-10-29, Dev B. PR33 review corrections refine the prior audit trust/ordering decision; see docs/AUDIT.md and PRD section 11 for the full contract.

Consumer lock requests time out after 250 ms, statements after one second, and transactions cooperatively cancel after two seconds. Each <=100-row batch loads the signed prefix once and derives its append tail internally. Synchronous full-history HMAC verification remains linear and cannot be preempted by asyncio; do not call this a hard CPU deadline.

Configured anchor transport failure stops settlement at startup and runtime, without persisting an integrity halt for transport alone. Restart verifies the chain and external checkpoint before money clients start. Apparent rollback gets two fresh reads after 250/500 ms outside transactions, then confirmed verification failure persists the R23 halt. CAS races may retry. Git has a shared 15-second deadline per complete read/publication; shutdown races the audit tick against stop and cancels/awaits it instead of waiting through all retries. Dedicated Git auth stays isolated and redirects remain disabled.

Render upgrade is manual: eligible maintenance halt/pause, owner-only migration0007 and actual restricted-login grant checks, stable private HMAC key, reviewed worker deploy/verification, then authorized maintenance resume. Runtime services never receive the owner URL. The temporary owner SQL procedure refuses to overwrite/clear incident halts; authenticated ops routing is still separate work.

Frontend transient REST failures retain an established SSE source, hide stale panes and preserve REPLAY; later valid notifications/open recover automatically. Auth/terminal failures close the source. Session/CSRF decisions and actual server SSE latency remain separate acceptance work.
