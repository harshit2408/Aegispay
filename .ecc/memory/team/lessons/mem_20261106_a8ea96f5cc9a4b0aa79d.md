The post-test hook reports "Tests failed" on wider `pytest tests/unit` runs because hypothesis is not installed locally (ModuleNotFoundError at tests/unit/test_audit_events.py). Install the dev extras or run the targeted test files. Bare `ruff` is not on PATH on Dev A's Windows machine; use `python -m ruff`.
