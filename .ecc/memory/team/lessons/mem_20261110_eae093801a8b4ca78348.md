Product integration b4e4f5f extends the SPIKE-9 durable receipt contract: recovery must retry an ordinary failed graph task, reconcile an accepted-but-unconsumed approval receipt (even when the approval was subsequently voided), and bind the approval ID to its original interrupt/checkpoint lineage and gate hash. A dedicated advisory-lock connection is watched; connection loss cancels the active dispatch. See backend/tests/unit/test_dispatch.py and decision/dispatch.py.

Migration 0011 restricts settlement UPDATE grants on vendor_master and requires an independently approved matching vendor_master_changes record with elapsed cooling before changing receiver identity/version. This corrects the runtime privilege gap that broad table UPDATE left despite route checks. Tests use the restricted database role; owner/superuser fixtures alone do not establish the guard.

Verification: 899 backend checks passed against local PostgreSQL16; separately added restricted API-login startup passed. EVAL.md records actual replay/SSE timings and limits. Synthetic replay is not live sandbox acceptance, and production deployment still requires owner migration plus Dev A review of R1–R4 changes. No secrets were read. Existing isolated-linux-verification skill covers repeated verification; no duplicate skill is needed.


CI follow-up on PR #40 at 63f5338: run 42768590779 passed backend (899 tests), frontend, harness and secret scanning, but Compose hung during API startup. PostgreSQL activity showed CREATE INDEX CONCURRENTLY checkpoints_thread_id_idx waiting on Lock/virtualxid while the reconciler's pg_try_advisory_lock connection remained idle in transaction. Session-level advisory locks do not require an open transaction. Keep the dedicated checked-out connection for lock ownership, but set isolation_level=AUTOCOMMIT before acquiring the lock. In the local disposable Compose reproduction, replacing/restarting the worker released the blocking transaction immediately; API health returned status=ok, db=true, demo=false, replay=false. The reconciler lock connection then showed state=idle and xact_start=NULL. The focused reconciler suite passed 29 tests in 14.54 seconds with Ruff check/format passing. Scope pg_stat_activity assertions to datname=current_database(): the first regression run otherwise observed another database’s old worker transaction. API health returned HTTP 200. Fresh CI remains pending with the parent. This is local startup evidence, not deployment or sandbox acceptance.
