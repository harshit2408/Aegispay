Product integration b4e4f5f extends the SPIKE-9 durable receipt contract: recovery must retry an ordinary failed graph task, reconcile an accepted-but-unconsumed approval receipt (even when the approval was subsequently voided), and bind the approval ID to its original interrupt/checkpoint lineage and gate hash. A dedicated advisory-lock connection is watched; connection loss cancels the active dispatch. See backend/tests/unit/test_dispatch.py and decision/dispatch.py.

Migration 0011 restricts settlement UPDATE grants on vendor_master and requires an independently approved matching vendor_master_changes record with elapsed cooling before changing receiver identity/version. This corrects the runtime privilege gap that broad table UPDATE left despite route checks. Tests use the restricted database role; owner/superuser fixtures alone do not establish the guard.

Synthetic replay is not live sandbox acceptance, and production deployment still requires owner migration plus Dev A review of R1–R4 changes. No secrets were read. CI follow-up on PR #40 at 63f5338: run 42768590779 passed backend (899 tests), frontend, harness and secret scanning, but Compose hung during API startup. PostgreSQL activity showed CREATE INDEX CONCURRENTLY checkpoints_thread_id_idx waiting on Lock/virtualxid while the reconciler's pg_try_advisory_lock connection remained idle in transaction. Session-level advisory locks do not require an open transaction. Keep the dedicated checked-out connection for lock ownership, but set isolation_level=AUTOCOMMIT before acquiring the lock. In the local disposable Compose reproduction, replacing/restarting the worker released the blocking transaction immediately; API health returned status=ok, db=true, demo=false, replay=false. The reconciler lock connection then showed state=idle and xact_start=NULL. The focused reconciler suite passed 29 tests in 14.54 seconds with Ruff check/format passing. Scope pg_stat_activity assertions to datname=current_database(): the first regression run otherwise observed another database’s old worker transaction. API health returned HTTP 200. Fresh CI remains pending with the parent. This is local startup evidence, not deployment or sandbox acceptance.


Browser integration follow-up (2026-11-11): graph-only replay checks do not exercise case-read response serialization. Actual Chromium S1–S4 against authenticated HTTP routes and disposable PostgreSQL exposed two failures in `routers/contracts.py`: PO-ledger execution identifiers have no ORM foreign key for an implicit join, and PostgreSQL `SUM(bigint)` returns `Decimal`, which strict `Cents` rejects. Use the explicit execution-ID join and convert the exact aggregate to `int` at the response boundary. The subsequent browser run passed S1–S4, detector-disabled freeze, duplicate-original linking and zero spend/PO/outbox rows in 18.0 seconds. This is synthetic replay evidence, not a live payout or hosted acceptance.

Repeated replay rehearsal against the same fixture can reach the velocity gate because `demo/reset` does not clear prior execution counts. Preserve that protective freeze. For an isolated rehearsal, restart the disposable fixture so it creates a fresh UUID-named database; do not clear ledgers or weaken velocity checks. Full reset semantics remain Dev A's P2-13 integration work. The existing isolated-Linux verification skill and `frontend/e2e/README.md` describe the verification setup; no duplicate skill is needed.

Verification follow-up (2026-11-12): when reusing a cached Linux test image with a new source archive, PYTHONPATH updates the test parent but a sandboxed `python -I` child ignores it and may import stale installed site-packages. Install the intended backend into the container and verify ordinary and isolated imports against the source snapshot before running parser acceptance. Export with `git -c core.autocrlf=false archive`: Windows autocrlf conversion can otherwise make generated mirror files differ only by CRLF even when the Git index contains LF. The existing `.claude/skills/isolated-linux-verification/SKILL.md` and generated Codex ports now record these checks.
