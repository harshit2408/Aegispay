Product integration b4e4f5f extends the SPIKE-9 durable receipt contract: recovery must retry an ordinary failed graph task, reconcile an accepted-but-unconsumed approval receipt (even when the approval was subsequently voided), and bind the approval ID to its original interrupt/checkpoint lineage and gate hash. A dedicated advisory-lock connection is watched; connection loss cancels the active dispatch. See backend/tests/unit/test_dispatch.py and decision/dispatch.py.

Migration 0011 restricts settlement UPDATE grants on vendor_master and requires an independently approved matching vendor_master_changes record with elapsed cooling before changing receiver identity/version. This corrects the runtime privilege gap that broad table UPDATE left despite route checks. Tests use the restricted database role; owner/superuser fixtures alone do not establish the guard.

Verification: 899 backend checks passed against local PostgreSQL16; separately added restricted API-login startup passed. EVAL.md records actual replay/SSE timings and limits. Synthetic replay is not live sandbox acceptance, and production deployment still requires owner migration plus Dev A review of R1–R4 changes. No secrets were read.
