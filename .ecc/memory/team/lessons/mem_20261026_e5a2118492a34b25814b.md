2026-10-26, Dev B. The API image installs backend runtime dependencies without [dev]. Importing product webhook verification crashed because cryptography was only a dev dependency; httpx was also used directly by product clients without an explicit runtime declaration. Declare both directly in backend/pyproject.toml rather than relying on a transitive or dev installation. PR #25 contains the minimal dependency correction and a portable Compose regression.

A passing backend[dev] suite does not establish production boot. Verify a runtime-only image becomes healthy with Postgres, runs as the aegis user and receives only the existing API environment allowlist; the parent observed {status: ok, db: true} without Treasury or audit secrets. Full integrated Linux Python 3.12/Postgres 16 suite passed 434/434 before transplanting the minimal change; PR #25 head 180b932 then passed all five CI jobs. No PayPal or LLM API calls occurred.

For Compose tests, use a temporary empty env file; Windows native paths such as NUL can become a nonexistent absolute /dev/null path inside Docker. The portable fixture test passes 3/3. Do not loosen environment isolation to make a runtime import succeed. Links: https://github.com/harshit2408/Aegispay/pull/25 ; docs/CHECKLIST.md owns task state.

Repeated isolated Linux verification is documented in .agents/skills/isolated-linux-verification/SKILL.md. Keep test provenance tied to the tested revision and remove only the owned temporary resources; the prior runtime and audit test resources were cleaned up. This procedure does not establish live sandbox or hosted behavior.
