2026-10-29, Dev B. The merged P2-04 synthetic PDF fixtures are ASCII-readable enough for Git core.autocrlf to treat them as text. A Windows checkout and git archive changed LF to CRLF and broke test_manifest_hashes_match_committed_files; the original Git blobs matched the manifest exactly. Mark *.pdf binary in .gitattributes. Restore only verified line-ending conversions from the existing blobs; do not regenerate PDFs, update hashes to corrupted files or weaken the manifest regression. Preserve byte-exact fixtures in verification archives.
