# Preserve unknown-result no-sync and cancellation idempotency in spike/harness reviews

2026-10-26 IST, P0-17 independent closeout review. PR1's initial-publication guard was insufficient: an existing upstream branch with a local commit still pushed when the test payload had stdout but no final exit status. A throwaway bare-remote regression first reproduced that push; requiring an explicit zero for every sync prevents it. The SPIKE5 cancellation POST also omitted PayPal-Request-Id; an offline call-capture regression first failed and now verifies a stable per-run cancel key. Regenerate both Claude/Codex hook mirrors and run their tests after source changes. Review: https://github.com/harshit2408/Aegispay/pull/1#pullrequestreview-5644945118 . No live API or credential file access was used.
