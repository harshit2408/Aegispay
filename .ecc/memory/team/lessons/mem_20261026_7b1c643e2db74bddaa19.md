SPIKE-10's poll-only PASS ignored failed or contradictory confirming GETs. A 2026-10-26 Dev B offline regression reproduced eleven false passes: HTTP errors, wrong receiver/type/amount/currency, changed terminal state and a missing item ID. The corrected probe requires successful batch and item GETs, item SUCCESS and the exact command fields from both. Printing a mismatch is not a validation gate.

Original live PAYPAL_ID evidence remains the 2026-10-23 sandbox run in PRD §18; this closeout made no further payout and accessed no credentials. Application settlement controls are still separate work. Task state belongs only in docs/CHECKLIST.md.
