Project .claude/settings.json enables ponytail, caveman and obsidian, but enabling is not installing: on Dev B's machine installed_plugins.json was empty and none were active (2026-10-22).
Fix per machine: /plugin install <name>@<marketplace> for each, then /reload-plugins. Dev A likely needs this too.
Related: ECC GateGuard hook demands "facts" before the first Bash/Write of each session. On Windows install Node first (see session log).
